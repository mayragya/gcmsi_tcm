# gcmsi_tcm
 Gestor de administracion de clinicas y servicio medico integral. Este sistema permite administrar y gestionar recursos como: doctores, pacientes, expedientes. Así como también movimientos o eventos en específico, por ejemplo: citas médicas. Es una solución tecnológica desarrollada en base a un caso de estudio realizado en la clínica "Torre centro médico". Se propone una solución adaptable a cualquier clínica y con amplias posibilidades de escalabilidad de servicios. 
 
 ##Tecnologías para el desarrollo 
 Las tecnologías utilizadas para el desarrollo de este proyecto son: PHP , HTML5, JavaScript y CSS. Todas son utilizadas en su versión vanilla. Backend con PHP, consumo de servicios y lpogica del lado del cliente con JS hechos por mí.
